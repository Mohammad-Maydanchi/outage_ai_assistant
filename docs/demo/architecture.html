How the flow works

  1. 1A new outage ticket triggers the agent (webhook, with a scheduled check as backup).
  2. 2Read the ticket and post a first update.
  3. 3Queue the job for pacing and retries.
  4. 4Start the call.
  5. 5Vapi calls the ISP.
  6. 6Gemini Flash handles the live conversation.
  7. 7The call result comes back to the agent.
  8. 8Gemini Pro extracts the report.
  9. 9Post the report back on the ticket.
  10. 10Escalate to a human if no answer or unclear.
